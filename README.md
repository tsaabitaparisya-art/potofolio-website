# Portfolio Website

Personal portfolio website developed using PHP, Bootstrap, JavaScript, and PHPMailer.

## Features

- Responsive Design
- Dark / Light Mode
- Typing Animation
- Projects Showcase
- Certificates Showcase
- Contact Form with PHPMailer
- GitHub Integration
- Figma Integration

## Technologies

- PHP
- Bootstrap 5
- JavaScript
- MySQL
- PHPMailer
